## Objective

Implement 4 ข้อที่รับรองแล้วใน `Requirements.md` (สถานะ ✅ ทั้งหมด):

- **R-002** — ปุ่ม icon นำทาง: หน้า Full = [ไปหน้ารวม] [เปิดเป็น Widget] [ปิด] · หน้า Overall = [ไปหน้า Full] [เปิดเป็น Widget] [ปิด] — ปุ่มย่อ chevron เดิมถูกแทนที่ทั้งสองหน้า, tooltip ไทย/อังกฤษผ่าน I18n, ปุ่มปิดทุกหน้ายังเคารพ Close Action (จาก R-005 ทาง (ก))
- **R-003** — widget resize แบบคงสัดส่วน (ลากแนวนอน→สูงตาม, แนวตั้ง→กว้างตาม) + เนื้อหา (ตัวอักษร/ค่า/แถบ) สเกลตามขนาด; คง FontScale มือไว้ใช้ร่วม
- **R-004** — ปุ่มเลื่อนซ้าย/ขวาของ widget เห็นชัดตลอดเวลา (ปัจจุบัน opacity 0.35 + margin ติดลบลอยพ้นขอบ) อยู่ด้านซ้าย/ขวาในขอบเสมอ
- **R-006** — ปุ่ม pause/play toggle หยุดการวนสลับหน้าของ widget (กดซ้ำวนต่อ); ค่ายังอัปเดตเวลาจริงขณะค้าง; badge `⏸ ค้าง`/`⏸ Paused` มุมบนซ้ายเฉพาะตอนหยุด; ปุ่มเลื่อนยังใช้ได้ขณะค้างโดยไม่หลุดการค้าง; ไม่บันทึกสถานะลง config
