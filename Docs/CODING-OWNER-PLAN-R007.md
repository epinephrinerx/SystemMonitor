## 3. จุดเสี่ยงที่ Reviewer ต้องเช็ก

**ก. การห่อแถบแท็บด้วย Grid ใหม่ กระทบการเลื่อนไหม**
- ScrollViewer ต้องอยู่ในแถว `*` ถ้าไปวางในแถว `Auto` หรือใส่ใน StackPanel ความสูงจะไม่ถูกจำกัด แถบเลื่อนจะไม่ขึ้นและแท็บจะล้นออกนอกหน้าต่าง
- วิธีเช็ก: ย่อหน้าต่าง Full ให้เหลือ 640×480 (`AppConfig.cs:123`) บนเครื่องที่มีแท็บเยอะ แท็บต้องยังเลื่อนได้และปุ่มนำทางต้องค้างอยู่ด้านบน

**ข. ความกว้างของแถบแท็บ**
- คอลัมน์เป็น `Auto` และ TextBlock ภายในถูกวัดด้วยความกว้างไม่จำกัด ข้อความ "เปิดเป็น Widget" + ไอคอน + padding อาจกว้างกว่า 128 ทำให้แถบกว้างขึ้นและพื้นที่กราฟแคบลง และ TextWrapping จะไม่ทำงาน
- วิธีแก้: ให้ `FullNav` มี `Width="{Binding ActualWidth, ElementName=TabsList}"` ปุ่มจะกว้างตามแถบแท็บและข้อความตัดบรรทัดเหมือน R-008 (ความกว้างของ ItemsControl ไม่ได้ขึ้นกับ FullNav จึงไม่เกิด layout loop)
- วิธีเช็ก: ทั้งไทยและอังกฤษ แถบต้องกว้างเท่าเดิม ข้อความไม่ถูกตัดหาย

**ค. ปุ่มต้องเป็น `ButtonBase` (`OverControl` ที่ `.xaml.cs:720-732`)**
- ใช้ `Button` จริงอยู่แล้ว การกดจะไม่ถูกตีความเป็นการลากหน้าต่าง (`:579`) และไม่โดนโซนปรับขนาดที่ขอบซ้ายกิน ซึ่งแถบอยู่ติดขอบซ้ายพอดี
- สิ่งที่ต้องไม่ทำ: เปลี่ยนเป็น `Border` + `MouseDown` เพราะจะไม่ถูกนับเป็น control
- วิธีเช็ก: คลิกปุ่มใกล้ขอบซ้ายสุด ต้องสลับหน้า ไม่ใช่เริ่มปรับขนาด และ cursor ต้องเป็นลูกศร (`:672`)

**ง. ดับเบิลคลิกบนปุ่ม**
- Button กิน MouseLeftButtonDown ไปแล้ว จึงไม่ควรไปเข้าเงื่อนไขวนโหมดที่ `:615-620`
- วิธีเช็ก: ดับเบิลคลิกปุ่ม ต้องไปหน้าที่ปุ่มระบุ ไม่ไปต่อเป็นหน้าถัดไปของวงจร

**จ. ปุ่มที่สร้างใหม่ทุกครั้งที่เปลี่ยนภาษา**
- ต้อง `Clear()` ก่อนเติม `FullNav` ไม่อย่างนั้นปุ่มจะซ้ำเป็น 4, 6 ปุ่มหลังเปลี่ยนภาษาหลายรอบ
- ผูก `Click` เป็น lambda บนปุ่มใหม่ทุกครั้ง (ไม่ใช้ handler จาก XAML) ปุ่มเก่าจะถูกเก็บทิ้งได้ปกติ

**ฉ. ปุ่มมุมขวาบนยังเหมือนเดิม**
- diff ต้องไม่แตะ `:478-494`, `:98-107` และ `UpdateHeaderTooltips` ยังตั้ง tooltip ครบ 4 ตัว

**ช. ธีมสว่าง/มืด**
- `SidebarButton` ใช้สีน้ำเงิน `#3b82f6` ตายตัว ต้องดูว่าอ่านออกบนพื้นแถบ Full ทั้งสองธีม
